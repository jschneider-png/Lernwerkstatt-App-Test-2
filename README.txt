SANITÄRTECHNIK 11 – SAISON-LAYER DELUXE

Diese Version verändert KEINE Kursinhalte und KEINE Links.
Sie ersetzt nur die zentrale saison.js und ergänzt Bilddateien.

UPLOAD:
1. Im Hauptverzeichnis saison.js ersetzen.
2. Den Ordner assets/saison/ mit allen enthaltenen Dateien hochladen.
3. Sonst nichts verändern.

Danach steuerst du nur diese Zeile in saison.js:
const SAISON = 'normal';

Mögliche Werte:
normal
halloween
weihnachten
fruehling
sommer

HALLOWEEN:
- animierter Zombie
- animierte Grimassen-Kürbisse
- Fledermaus-Silhouetten
- dunkler Hintergrund / Glow

WEIHNACHTEN:
- animierter stehender Weihnachtsmann
- zweiter Weihnachtsmann im Schlitten fliegt durchs Bild
- Schnee
- Lichterkette
- Winterhintergrund

FRÜHLING:
- Himmel / Wiese
- Sonne
- animierte Blumen
- frische, helle Farbwelt

SOMMER:
- Himmel / Wasser / Strand
- große Sonne
- Sonnenschirm
- Liegestuhl
- sommerliche Farbwelt

NORMAL:
- keine Saison-Deko
- der vorhandene Kurs bleibt neutral

Die Figuren liegen nur an den Rändern und blockieren keine Buttons.
Bei 'Bewegung reduzieren' des Betriebssystems werden starke Animationen reduziert.
