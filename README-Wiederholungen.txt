LERNWERKSTATT – WIEDERHOLUNGEN BW01 BIS BW12

INSTALLATION
1. Alle fünf HTML/JS/TXT-Dateien in das Hauptverzeichnis deines GitHub-Repositories hochladen. Die bestehende index.html ersetzen. Bilder und alle bisherigen Dateien unverändert lassen.
2. Auf GitHub Pages index.html neu laden. Die neue Wiederholungskarte erscheint unter CODE BLAU.
3. Die 12 Wiederholungen stehen unter wiederholungen.html bereit.

PFLEGE OHNE ÄNDERUNG AN HTML
Bearbeite ausschließlich wiederholungen-inhalte.js:
- AKTUELLE_WIEDERHOLUNG = 1 bedeutet: in BW02 wird BW01 wiederholt. In BW03 setze den Wert auf 2 usw.
- Je Blockwoche: titel, dauer, punkte, intro, status und die vier stationen.
- In jeder Station: title, leitfrage, info, auftrag, q, options, answer (0=erste, 1=zweite, 2=dritte Antwort), feedback, materialien.
- Für Materiallinks auf Blockwochenebene: "materialien": [{"titel":"Arbeitsblatt PDF","url":"materialien/bw01/arbeitsblatt.pdf"}]
- Für Materiallinks auf Stationsebene dieselbe Syntax bei der jeweiligen Station verwenden.
- Eigene PDF/Bilder/Dokumente nach GitHub hochladen, z.B. in materialien/bw01/. Für externe Links die vollständige https://-Adresse eintragen.
- YouTube- und H5P-Links können als externe Links geöffnet werden. Ein Upload über die Schülerseite ist NICHT enthalten: Materialien werden von der Lehrkraft über GitHub gepflegt.
- status "vorbereitung" blendet die Startmöglichkeit aus, "verfuegbar" schaltet frei.

DIDAKTIK / WICHTIGE HINWEISE
- Vier Lernstationen pro Blockwoche auf Basis des übermittelten Jahresplans mit jeweils Lernkarte, Selbstkontrollfrage und Transferauftrag.
- 20–25 Minuten sind eine PLANUNGSZEIT, keine technische Mindestlaufzeit. Für mindestens 15 Minuten sollten die Transferaufträge verbindlich sein.
- Die XP sind Übungspunkte für Antworten beim ersten Versuch, kein gesicherter Leistungsnachweis. Notizen werden nur im aktuellen Browserfenster eingegeben und nicht übertragen oder gespeichert.
- Keine H5P-Datei: Die Interaktionen sind browserbasierte HTML/JS-Übungen.
- Die Inhalte sind kompakte fachliche Einstiegstexte. Insbesondere Bemessungs-/Normtabellen und aktuelle Grenzwerte müssen durch Unterrichtsmaterialien ergänzt werden; keine verbindlichen technischen Bemessungsentscheidungen nur aus den Lernkarten ableiten.
- In BW02 wird BW01 wiederholt; BW12 kann in einer anschließenden Abschluss-/Wiederholungsphase genutzt werden.
