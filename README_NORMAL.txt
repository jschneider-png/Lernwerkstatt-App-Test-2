SANITÄRTECHNIK 11 – NORMALE / RUHIGE STARTSEITE

Diese Version ist bewusst neutral:
- keine Halloween-Deko
- keine Weihnachts-Deko
- keine Frühlings-/Sommer-Deko
- kein Saison-Umschalter für Schüler
- keine auffälligen Saisonanimationen
- ruhige Blau-/Grün-/Orange-Kursoptik

UPLOAD:
Wenn du eine komplett ruhige Startseite möchtest, ersetze im Hauptverzeichnis
nur die vorhandene index.html durch diese index.html.

Deine Links und die Datei kurs-links.js werden dadurch NICHT verändert.

HINWEIS:
Die übrigen Kursseiten können weiterhin zentral über saison.js gesteuert werden.
Für komplette Ruhe im ganzen Kurs setze dort zusätzlich:
const SAISON = 'normal';
