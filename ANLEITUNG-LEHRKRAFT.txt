SANITÄRTECHNIK – ZENTRALE LEHRKRAFT-PFLEGE
========================================

Nur die Datei lehrkraft-inhalte.js bearbeiten.
Sie liegt direkt im Hauptverzeichnis des GitHub-Repositories.

1. GitHub öffnen -> lehrkraft-inhalte.js anklicken.
2. Auf das Stift-Symbol (Edit this file) klicken.
3. Eigene Inhalte zwischen die einfachen Hochkommas eintragen.
4. Commit changes anklicken. GitHub Pages aktualisiert sich danach.

ABSCHNITTE:
KURS_LINKS       Links zu Mebis, Drive, Videos, Arbeitsblättern je Blockwoche
STUNDEN_LINKS    Direkte Links zu einzelnen Stunden
ZUSATZINHALTE    Texte, Bilder und Tipps zu Stunden im Lernpfad
MODULE           Kommentare, Bilder und Praxistipps für Module der VK-BW02 bis VK-BW12
MISSIONEN        Kommentare, Hinweise und Zusatzlinks für die 5 Escape-Room-Fachlabore

BEISPIEL:
MISSIONEN: {
  1: {kommentar:'Achtet auf die Löslichkeit von Salzen.',
      hinweis:'Vergleicht mit der Trinkwasserinstallation.',
      link:'https://beispiel.de/material.pdf',
      linktext:'Arbeitsblatt öffnen'},
  ...
}

WICHTIG:
- Zeichen zwischen den Hochkommas verändern, nicht die Klammern oder Kommas.
- Ein einzelnes Hochkomma im Text als \' schreiben.
- Eigene Bilder im Repository hochladen und relativen Bildpfad eintragen.
- Die Mission ist ein statisches Lernspiel: Zugangscodes sind nicht sicher geheim.
- Keine personenbezogenen Schülerdaten in diese öffentliche Datei schreiben.
- Vor dem Unterricht alle Links und Rätsel testen.

Die übrigen HTML-Dateien musst du für normale Ergänzungen nicht mehr bearbeiten.
