SANITÄRTECHNIK 11 – EINFACHE LINKPFLEGE

Austauschen:
- lernpfad.html
- bei Nutzung der BYCS-Einbettung zusätzlich lernpffad-bycs.html

LINKS EINTRAGEN:
1. Datei öffnen.
2. Nach KURS_LINKS suchen.
3. URL zwischen die Hochkommas einfügen.
4. Speichern und bei GitHub ersetzen.

Je Blockwoche gibt es jetzt:
- Mebis
- Drive
- Arbeitsblätter
- Zusatzmaterial
- Videos
- Weitere Links
- Virtuelles Klassenzimmer (wenn vorhanden)

Beispiel:
1: {
  mebis: 'https://lernplattform.bycs.de/mod/...',
  drive: 'https://drive.google.com/...',
  arbeitsblaetter: 'https://lernplattform.bycs.de/mod/folder/...',
  zusatzmaterial: 'https://drive.google.com/...',
  videos: 'https://lernplattform.bycs.de/mod/page/...',
  weitereLinks: 'https://...'
}

Leere Felder bleiben als deaktivierte Buttons sichtbar.

OPTIONAL PRO STUNDE:
Nach STUNDEN_LINKS suchen.
Dort kannst du für Stunde 1–4 ebenfalls einfach je einen Link eintragen.

Die bereits vorhandenen Fachtexte, Übungen, Fun Facts, interaktiven Lernlandkarten und ZUSATZINHALTE bleiben erhalten.
