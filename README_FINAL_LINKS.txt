NEU:
Jede Stundenkarte hat jetzt zwei Buttons:
1. 📘 Lerneinheit öffnen
2. 🎓 Mebis & Materialien

Der zweite Button öffnet eine eigene Materialseite für genau diese Stunde.

Auf der Materialseite gibt es:
- Mebis
- Arbeitsblatt
- Drive / Dateien
- Zusatzmaterial
- Video
- Weitere Links

ZENTRALE LINKPFLEGE:
Alle Links werden ausschließlich in kurs-links.js gepflegt.
Dadurch verschwinden deine Links künftig NICHT mehr, wenn wir Design,
Halloween, Weihnachten oder andere HTML-Seiten ändern.

WICHTIG ZU DEINEN BISHERIGEN LINKS:
Die konkreten URLs, die du bereits selbst in GitHub eingetragen hattest,
liegen nicht in den Dateien, die mir hier vorliegen.
GitHub speichert aber die ältere Version im Dateiverlauf.

Du kannst aus einer früheren lernpfad.html die URL-Werte retten und EINMAL
in kurs-links.js eintragen. Wenn du mir diese alte lernpfad.html hochlädst,
kann ich die Links auch automatisch für dich übertragen.
