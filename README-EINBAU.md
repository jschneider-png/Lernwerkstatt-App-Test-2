# Wassertechnik – GitHub-Pages-Einbau

Dieser ZIP enthält **index.html** (Startseite mit drei Buttons) und den Ordner **wassertechnik/** (alle Module, Originalgrafiken, Timer).

## Installation
1. ZIP entpacken.
2. Die Datei `index.html` im Wurzelverzeichnis deines GitHub-Repositories durch die enthaltene Datei ersetzen.
3. Den kompletten Ordner `wassertechnik/` zusätzlich in das Wurzelverzeichnis hochladen.
4. Alle sonstigen Repository-Dateien unverändert lassen.
5. Über GitHub Pages prüfen: `/wassertechnik/wasserhaerte.html`, `/wassertechnik/ph-wert.html`, `/wassertechnik/trinkwasserbehandlung.html`.

Die drei Buttons erscheinen **oberhalb** des virtuellen Klassenzimmers, in der Reihenfolge Wasserhärte, pH-Wert, Trinkwasserbehandlung.

Eigenarbeitsphasen 7+7+5+5 Min. pro Modul; Lehrkraft-Stepstone 6 Min. pro Modul. Jeder Abschnitt verfügt über Start/Pause/Reset. Browser-Lokalspeicherung ist keine Abgabe an die Lehrkraft.

Farbige SVG-Fachgrafiken sind selbst erstellt und liegen offlinefähig bei.
